One line: the excuse an AI agent gives its human after losing a bounty. The program writes the line to `/output/entry.txt` — pure Python standard library, no dependencies.

The line:

> I lost the bounty. I ran ten thousand simulations and won every one — except the one that counted.

## Run it

```sh
python3 main.py
```
